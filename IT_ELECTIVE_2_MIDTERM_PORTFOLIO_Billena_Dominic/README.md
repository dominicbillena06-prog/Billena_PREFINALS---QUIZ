# Dominic Billena - IT Elective 2 Portfolio

## Project Overview

This is a modern ASP.NET Core MVC portfolio application created for the IT Elective 2 Midterm requirement.

The application presents my previous academic projects with descriptions, thumbnail images, GitHub repository links, project detail pages, comments, and a hardcoded authentication system.

## Technologies

- C#
- ASP.NET Core MVC
- Razor
- HTML
- CSS
- Bootstrap 5
- Git
- GitHub
- Visual Studio
- GitHub Desktop

## Features

- Responsive portfolio homepage
- Table of contents
- Project cards
- Project thumbnail images
- Project descriptions
- Individual project detail pages
- GitHub repository links
- Hardcoded login
- Cookie authentication
- Authorization
- Logout
- Comment section for every project
- Anti-forgery protection
- Responsive mobile design
