# Dominic Billena - IT Elective 2 Portfolio

## Project Overview

This is a modern ASP.NET Core MVC portfolio application created for the IT Elective 2 Midterm requirement.

The application presents my academic projects with descriptions, thumbnail images, GitHub repository links, individual project detail pages, comments, and a hardcoded authentication system.

## Technologies

- C#
- ASP.NET Core MVC
- Razor
- HTML
- CSS
- Bootstrap 5
- Git
- GitHub
- Visual Studio
- GitHub Desktop

## Features

- Modern responsive portfolio design
- Responsive homepage
- Navigation bar
- Login button
- Hardcoded authentication
- Cookie authentication
- Authorization
- Logout
- Table of contents
- Project cards
- Project thumbnail images
- Project descriptions
- Individual project detail pages
- GitHub repository links
- Comment section for every project
- Anti-forgery protection
- Responsive mobile layout
